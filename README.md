# 🌌 ParticleSphere

An interactive 3D particle visualization built with Three.js and GSAP. Transform a dynamic particle sphere into custom text with smooth animations and real-time rendering.

## ✨ Features

* Interactive 3D particle sphere
* Convert custom text into particle formations
* Smooth GSAP-powered animations
* Modern glassmorphism user interface
* Real-time rendering using Three.js
* Responsive design for desktop and mobile devices
* High-performance WebGL graphics

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Three.js
* GSAP (GreenSock Animation Platform)

## 🎮 How It Works

1. Open the application in your browser.
2. Enter any text in the input field.
3. Click the transform button.
4. Watch the particle sphere smoothly morph into your text.
5. Enter new text to create different particle formations.
